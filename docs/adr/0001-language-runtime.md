# ADR 0001: language: runtime

**Status:** Accepted (locked — MPE-63 megaplan)

## Decision

Language & runtime — C#/.NET 10

## Consequences

All LOLA base development is C# on .NET 10 (LTS). Third-party components must be free/open-source or freely licensed; no licensed/paid modules. Infra services (OpenBao, MinIO, ClamAV, Seq, Jaeger) run as deployed services so copyleft does not propagate to source.
